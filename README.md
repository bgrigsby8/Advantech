# Module Advantech

Viam modular sensor component for the [Advantech ADAM-4117](https://www.advantech.com/en/products/gf-ifx8/adam-4117/mod_77a1e4a9-71fe-4d90-bdd8-87ed92b92bdc) 8-channel analog input module. Communicates over RS-485 serial using the ADAM ASCII protocol and exposes each channel's voltage reading as a Viam sensor.

## Models

- [`brad-grigsby:Advantech:adam-4117`](brad-grigsby_Advantech_adam-4117.md) - Reads analog input channels from an ADAM-4117 over RS-485 serial
